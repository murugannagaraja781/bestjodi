# BestJodi Matrimony Web Application

Production-ready matrimonial web portal with automated deployment, containerization, database management, and maintenance tools.

## 🚀 Quickstart

### 1. Launch Stack
```bash
./autoscript.sh start
```

### 2. Interactive CLI Menu
```bash
./autoscript.sh menu
```

### 3. Port Mappings
- **Web App**: [http://localhost:8080](http://localhost:8080)
- **Admin Panel**: [http://localhost:8080/admin](http://localhost:8080/admin) (`admin1` / `admin1`)
- **phpMyAdmin**: [http://localhost:8081](http://localhost:8081) (`root` / see `.env`)

### 4. 1-Click Cloud VPS Deployment
```bash
sudo bash scripts/deploy_vps.sh
```
